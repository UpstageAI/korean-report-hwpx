# Security Policy

## Supported versions

Only the latest release on PyPI (`korean-report-hwpx`) is supported. Please upgrade before reporting.

## Reporting a vulnerability (보안 문제 제보)

Do not open a public issue. Use GitHub's private vulnerability reporting: the repository's **Security** tab → **Report a vulnerability**. 보안 문제는 공개 이슈 대신 Security 탭의 "Report a vulnerability"로 알려 주세요.

Include the version, the steps to reproduce, and the impact. We will acknowledge the report through the same private advisory.

## Secrets

Never include API keys such as `LAW_OC` or `UPSTAGE_API_KEY`, tokens, or personal data in issues, pull requests, logs, or test fixtures. If a key was exposed, revoke it with the issuer first.
