# 쪽수 정답 자료 (한글 실측)

맥 한컴오피스 한글에서 korean-report-hwpx 0.4.1로 만든 파일을 열어 상태 표시줄의 쪽수를 읽은 값이다(2026-11-07).
보고서 표준 서식(공통, style=standard, report_kind=standard). 붙임은 붙임마다 새 쪽에서 시작한다.

| 파일 | 본문 쪽수 | 전체 쪽수 | 비고 |
|---|---|---|---|
| lines20_body1.json | 1 | 1 | 소제목 4 + 한 줄 항목 16 = 20줄, 1쪽을 거의 채움 |
| lines21_body2.json ~ lines32_body2.json | 2 | 2 | 21줄부터 2쪽으로 넘어감 |
| run4_body1.json | 1 | 3 | 본문 1쪽 + 붙임 2개 |
| run5_body2.json | 2 | 7 | 본문 2쪽 + 붙임 5개 |

run4·run5는 실제 회의 결과 보고서의 한글 음절을 다른 음절로 바꾼 것이다(글자 폭이 같아 줄 배치·쪽수가 같음을 한글에서 확인).
