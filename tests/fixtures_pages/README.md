# 여러 쪽 보고서 쪽수 정답 자료 (한글 실측)

맥 한컴오피스 한글에서 korean-report-hwpx 0.5.0으로 만든 파일을 열어 상태 표시줄의 전체 쪽수를 읽은 값이다(2026-11-08).
`마지막쪽_채움`이 있는 문서는 한글에서 '저장하기'로 줄 배치(hp:lineseg)를 기록하게 한 뒤, 본문 마지막 요소의 끝 위치 / 본문 높이(70014)로 계산했다.
본문 글은 한글 음절을 다른 음절로 바꾼 것이다(글자 폭이 같아 배치가 같다). `manifest.json`에 파일별 서식(style, report_kind)과 정답이 있다.

| 묶음 | 개수 | 내용 |
|---|---|---|
| short_* | 12 | 한 줄 항목만, 2·3·4쪽 경계 앞뒤 |
| long_* | 12 | 3~4줄 문단, 쪽 경계에서 문단이 나뉘는 경우 포함 |
| table_* | 8 | 문단 + 7행 표 반복 |
| mix_* | 16 | 실제 보고서 블록(표·표 제목·3단계·참고 표시)을 섞음, 표준·내부결재·간소화 서식, 일부 붙임 |
| big_* | 6 | 25행·15행 표가 쪽 경계를 넘음(머리행 반복, 마지막 행 이동) |

붙임이 있는 mix 문서는 상태 표시줄로 전체 쪽수만 확인해 `본문_쪽수`를 적지 않았다.
