## 0. 구간 구분 방법
- 문단마다 zone 필드 부여: 머리 / 본문 / 담당 / 참고 (기존 paras.jsonl은 변경 없음, 별도 파일로 생성함)
- 머리: 표 밖 25자 이상 첫 문장 전까지
- 담당: 담당부서·담당자 + 전화번호가 든 표부터
- 참고: 「참고 N」「붙임 N」「별첨」으로 시작하는 상자 표(2행 이하) 또는 60자 미만 문단부터 문서 끝 또는 다음 담당 표까지
- 본문 끝 「붙임 1. 사진자료」식 첨부 목록(6문단 안에 담당 표가 이어지는 경우)은 구간 시작에서 제외함
- 문단마다 snippet(앞 30자) 필드 추가, 표·그림은 kind=tbl/pic 행으로 별도 기록(행·열 수, 첫 행 칸 글꼴·크기·굵기·정렬·배경색)

## 3. 기관별로 크게 갈리는 항목
- 2계층 기호: ㅇ 19곳, ○ 13곳, ◦ 6곳, ❍ 2곳 — 기관별 규칙 사용 필요함
- 1계층 글꼴: 휴먼명조 13곳, HY헤드라인M 9곳, 함초롬바탕·바탕 각 4곳
- 기호 없는 문단(p): 글꼴 일치율 32%, 크기 34%, 줄 간격 39% — 사실상 기관·문서별 자유 서식
- 빈 줄 크기(□→ㅇ, ㅇ→ㅇ): 일치율 30% 안팎, 3~10pt 분산
- 제목 상자 라벨칸 배경색, 표 머리 배경색: 기관별 고유 색상 사용(일치율 20~29%)
- ※ 기호 앞 공백: 0·1·3·4 분산(일치율 32%)

## 4. 본문 규칙과 보고서 규칙이 다른 항목 (같은 기관 내 비교, rules_report/_본문대비.json)
- 본문 방식: 29/42 기관에서 다름 — 본문은 문단식(기사체) 위주, 참고 구간은 □식으로 전환됨
- 빈 줄 크기: □→ㅇ 16/18, ㅇ→ㅇ 15/17, ㅇ→□ 12/13 기관에서 다름 — 참고 구간이 대체로 더 촘촘함(□→ㅇ 본문 8pt → 참고 6pt)
- 글꼴: 본문 바탕 계열 → 참고 휴먼명조로 바뀌는 기관 다수(1계층 19/25, 2계층 21/30)
- 크기: 2계층 21/30 기관에서 다름, 전체 최빈 본문 13~14pt → 참고 15pt
- 표 머리: 배경색 28/37, 크기 25/37 기관에서 다름 — 본문 표는 무배경·10pt, 참고 표는 연청 배경·12pt·굵게
- 들여쓰기: * 앞 공백 22/30(본문 2 → 참고 4), ※ 앞 공백 19/22 기관에서 다름
- 기호 문단 아닌 일반 문단: 본문 앞 공백 2(기사체 첫 줄 들여쓰기) → 참고 0
- 동일 유지 항목: □·-·*·※ 기호 자체, 기호 뒤 1타, □ 앞 공백 0, 표 머리 가운데 정렬

## 5. 한계
- 구간 시작 판정은 「참고·붙임·별첨」 표시 기반 휴리스틱임. 표시 없이 이어지는 보고서 페이지는 본문으로 분류됨
- 제목 상자는 첫 칸(라벨칸) 서식만 집계함. 제목칸 글꼴은 별도 집계 필요함
- 포스터·사진 위주 붙임(그림만 있는 구간)은 텍스트 규칙에 영향 없음, 상자 집계에는 포함됨

## 내어쓰기
- 둘째 줄은 기호 뒤 첫 글자(괄호면 괄호)에 맞춤: 앞머리 라벨 문단('□ (방식) 누리집…')도 '('에 맞춤('누' 아님). 내어쓰기 = 기호 앞 공백 + 기호 + 기호 뒤 공백, 라벨 유무와 무관함. 라벨은 자간 0·장평 100 고정
