## 0. 대원칙 (공식 기준)
1. 항목이 두 줄 이상이면 **둘째 줄부터 항목 내용의 첫 글자에 맞춘다** (한글: 기호·공백 뒤에서 Shift+Tab = 내어쓰기)
2. 항목 기호와 내용 사이는 **1타**(한글 반 칸=공백 1개)
3. 하위 항목은 상위 항목 위치에서 **2타(한글 1자)씩** 오른쪽으로
4. 한 문서 안에서는 같은 형식으로 통일
5. 날짜 `2026. 10. 7.(수)`, 시각 `14:00`(24시각제·쌍점), 항목이 하나뿐이면 기호를 붙이지 않음

## 1. 본문 방식 — 기관마다 다름 (가장 중요)
- **문단식(기사체)**: 기호 없이 첫 줄을 공백 2칸(또는 1칸)으로 시작하는 문단. 전체 본문의 다수.
  - 행안부 86%, 산림청 96%, 외교부 83%, 인사처 91%, 조달청 86%, 경찰청 84%, 보훈부 90% 등
- **□식(개조식)**: □ → ㅇ(○) → - → * 계층
  - 국토부 82%, 국조실 82%, 국세청 73%, 국방부 87%, 성평등부 85%, 소방청 84%, 재외동포청 95%, 새만금청 88%
- 혼합: 복지부·고용부·농진청 등은 문단식 위주에 □식 일부
- ⇒ **생성기는 기관의 본문 방식을 먼저 정하고, 원고를 그 방식으로 써야 함** (□식 기관에 문단식, 문단식 기관에 □식 금지)

## 2. 항목 기호별 실측 규칙
| 계층 | 기호(빈도) | 기호 앞 공백 | 기호 뒤 공백 | 글꼴·크기(최빈) | 내어쓰기 |
|---|---|---|---|---|---|
| 1 | □ (3,050) | 0 | 1 | 바탕/휴먼명조 14~15pt | **1.5칸** (□ 1 + 공백 0.5) |
| 2 | ㅇ (3,104) / ○ (1,792) / ◦ ❍ | **1** | 1 | 바탕/휴먼명조 14~15pt | **2.0칸** (공백 0.5 + ㅇ 1 + 공백 0.5) |
| 3 | - (1,445) | **2~3** | 1 | 같은 본문 글꼴 14~15pt | 2.1~2.5칸 (공백 수×0.5 + - 0.5 + 0.5) |
| 주석 | * (3,029) | 1~4 | 1 | **맑은 고딕 12pt**(별도 글꼴·작게) | 공백 수×0.5 + 1.0칸 |
| 참고 | ※ (629) | 0~3 | 1 | 맑은 고딕 12pt | 공백 수×0.5 + 1.5칸 |
- **내어쓰기 공식**: `내어쓰기 = (기호 앞 공백 수 × 0.5 + 기호 폭 + 기호 뒤 공백 수 × 0.5) × 글자 크기`
  - 기호 폭: □ ○ ㅇ ◦ ❍ ① ※ = 1칸, - * = 0.5칸, `1.` = 1칸
  - 실측 검증: ㅇ(앞1·뒤1) 2,386건 중앙값 2.04칸, □(앞0·뒤1) 2,309건 1.51칸, -(앞3·뒤1) 557건 2.49칸
- **앞머리 라벨 문단**('□ (방식) 누리집…', 라벨 '(…)'·'〔…〕'·'[…]' 2~6자 + 공백): 라벨 뒤 첫 글자에서 Shift+Tab — `내어쓰기 = 위 공식 + 라벨 폭(자간 0·장평 100 고정) + 라벨 뒤 공백`. 라벨 없는 문단은 위 공식 그대로
- 왼쪽 여백은 거의 항상 0 — 계층은 **여백이 아니라 기호 앞 공백 수**로 표현
- 줄 간격 160% 최빈(150·170도 흔함), 문단 위아래 간격은 대부분 0 (간격은 빈 줄로 만듦)

## 3. 문단 사이 간격 = 크기 다른 빈 줄
| 앞 → 뒤 | 빈 줄 크기(중앙) | 비고 |
|---|---|---|
| □ → ㅇ | 8pt (6·10도 흔함) | 514건은 빈 줄 없이 붙임 |
| ㅇ → ㅇ | 6pt (5·8) | 974건은 붙임 |
| ㅇ → □ | 10~11pt | 다음 □ 앞은 넓게 |
| □ → □ | 10pt | |
| 문단 → 문단(문단식) | 14pt(본문 크기 한 줄) 또는 10·7pt | |
| 문단/ㅇ → * 주석 | **붙임(빈 줄 없음)** 또는 3~4pt | 주석은 바로 위 문단에 딸림 |
| 표 → 다음 문단 | 10pt | |
| 표 → 표 | 3pt | |
- 원칙: **상위 항목이 바뀔수록 간격이 크고, 하위로 갈수록 작아지며, 주석은 붙는다**

## 4. 줄 끝 정리 (자간)
- 본문 자간: 0이 최빈이지만 **-1~-10을 문단별로 조정**한 문서가 다수 (-2·-3·-5·-4 순)
- 마지막 줄 채움 분포(10분위): 19%·30%·40%·51%·61%·70%·79%·87%·94% — **20% 미만 짧은 마지막 줄은 10%뿐**
- ⇒ 규칙: 마지막 줄이 한두 어절(20% 미만)로 남으면 자간을 -1씩 조여 한 줄 줄이거나 채움 30% 이상 확보, 자간 하한 -10
- 한글 줄 나눔 기준: 원본은 대부분 **글자 단위**(HWPX 값 KEEP_WORD). 생성기는 **어절 단위**(BREAK_WORD)로 써서 어절 중간 끊김을 막음

## 5. 제목·부제
- 제목: **함초롬돋움 26pt 굵게 가운데**(2,010/2,110), 1줄 57%·2줄 39%, 검정
- 부제: `- … -` 형식, **함초롬바탕 14pt 가운데**, 굵지 않음이 다수, 1~2개
- 제목·부제는 머리 표(상자) 안 별도 칸

## 6. 표
- 머리행: **맑은 고딕 10~12pt 굵게, 가운데**, 음영 `#DFE6F7`(연파랑) > `#F2F2F2` > `#D9D9D9`
- 본문: 맑은 고딕(또는 한양중고딕) 10~12pt 보통, 줄 간격 100~160%
- 정렬: **숫자 칸 = 가운데 또는 오른쪽**, 짧은 글(10자 이하)·구분 열 = 가운데, 긴 글 = 양쪽 정렬
- 표 제목은 `< 제목 >` 형식, 표 위 가운데

## 7. 엔진에 반영할 것 (다음 단계)
1. 기관별 **본문 방식(문단식/□식)** 판정 → 원고 구조 작성(사용자 AI, get_writing_guide)부터 그 방식으로
2. 내어쓰기를 복제하지 말고 **공식으로 계산**해 문단 모양을 만듦
3. 계층별 빈 줄을 위 표대로 (기관 실측값 우선, 없으면 전체 중앙값)
4. 주석(*)은 맑은 고딕 12pt·위 문단에 붙임
5. 문단별 자간 조정(하한 -10)으로 짧은 마지막 줄 방지
6. 표: 머리행 굵게·음영·가운데, 숫자 오른쪽/가운데, 긴 글 양쪽 정렬, 칸 안 여러 줄 보존, 한컴 전용 문자(PUA) 처리
7. 검증: 기관 원본 보도자료를 그 기관 규칙으로 재생성 → 원본과 한글 화면 대조
